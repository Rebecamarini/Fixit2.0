# Domain docs

Layout: contexto único, com `CONTEXT.md` e `docs/adr/` na raiz.

Antes de explorar, ler `CONTEXT.md` e ADRs relevantes em `docs/adr/`. Se ausentes, prosseguir; criar documentos quando termos ou decisões forem definidos. Usar o vocabulário do contexto e explicitar conflitos com decisões existentes.
