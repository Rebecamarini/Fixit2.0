# Issue tracker

Fonte das tarefas: https://trello.com/b/SsT0I7Di/backlog-do-produto-fixit
Repositório: https://github.com/Rebecamarini/Fixit2.0

Consultar cartões e checklists pelo conector Trello. Referenciar o cartão no planejamento e nos PRs. Registrar o progresso no cartão correspondente e conferir a atualização. Não criar tarefas duplicadas no GitHub Issues.

Não transportar conclusões ou estados de implementação da versão antiga para a nova. Distinguir cartões do MVP de registros históricos. Preservar responsáveis e listas, salvo instrução para alterá-los. PRs externos não são uma superfície de triagem.
