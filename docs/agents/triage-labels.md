# Triage labels

| Papel | Etiqueta no Trello | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Precisa de avaliação |
| needs-info | needs-info | Aguarda informações |
| ready-for-agent | ready-for-agent | Especificada e pronta para agente |
| ready-for-human | ready-for-human | Requer implementação humana |
| wontfix | wontfix | Não será executada |

Usar esses nomes como etiquetas do Trello, criando-as quando necessárias. Preservar etiquetas de prioridade e listas existentes.
