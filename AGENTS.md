# Preferências gerais

## Perguntas com opções

Preferir o seletor interativo nativo, em grupos de até três perguntas relacionadas. Não interpretar o aceite de uma pergunta assíncrona como resposta. Se indisponível, explicar a limitação.

## Grill e implementação

Encerrar entrevistas de grill consolidando entendimento e spec. Aprovar respostas ou spec não autoriza implementar; aguardar pedido claro e separado.

## Agent skills

### Issue tracker

Antes de selecionar, planejar ou executar tarefas, leia `docs/agents/issue-tracker.md`. Tarefas no Trello; GitHub para código e PRs. PRs externos não entram na triagem.

### Triage labels

Ao fazer triagem, use os cinco nomes padrão descritos em `docs/agents/triage-labels.md`.

### Domain docs

Antes de explorar ou implementar, leia `CONTEXT.md` e os ADRs relevantes em `docs/adr/`. Layout de contexto único; regras em `docs/agents/domain.md`.

### Stack

Antes de alterar código Next.js, consulte a documentação instalada em `node_modules/next/dist/docs/`. Use a versão antiga apenas como referência técnica; não importe suas funcionalidades ou credenciais automaticamente.
